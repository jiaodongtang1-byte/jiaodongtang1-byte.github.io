# 成都版（清水河水校区·六藏）现场采集 SOP

版本：2026-09-08。适用对象：成都侧执行人（策划人/受托同学）。

## 一、母版规划（最终形态）

- 场景：电子科技大学清水河校区 + 步行 15-30 分钟圈，受赠人**自己走全程**（无人带路）。
- 六关 = 校园六藏·回忆/彩蛋探点：每关解锁一段写给受赠人的话/彩蛋（内容后补），
  非购物任务。第一关（prologue）= 交付"装了 App 的 iPad/手机"后开始。
- 名字/日期/年岁：全部占位符 `{{TA}}`、`{{BIRTHDAY}}`、`{{AGE}}`，真值后补，改一处生效。

## 二、你需要做的三件事（就是"数据采集"，其余我包）

### 任务 1：确定六个探点（选点）

候选方向（以校内公告/在校生事实为准，**别猜名字**——写进 App 的地名必须准确）：

- 确定性地标：西源大道校门/主楼、图书馆、品学楼、成电会堂、大体育场/田径场、
  主楼前银杏大道、校内湖泊（湖名以现场为准）、东门/西门广场。
- 步行圈（15-30 分钟）：西源大道路口、犀浦商圈方向、有轨电车蓉 2 号线站，
  以及你熟悉的任何"有故事/有仪式感"的点（一楼咖啡角、某棵银杏、某块石头……）。
- **产出**：6 个点一句话一句话叙（该点是谁的回忆/悬念/彩蛋？）+ 人形/景别（见任务 2）。

六关节奏建议（自走版）：序章(拿到设备)→关1(校内必到打卡)→关2(校内记忆点)→
关3(校内小任务)→关4(校园边缘)→关5(步行圈店铺/口)→终章(最后一个礼/信)。
**六关全部无 30 米购买门槛烦恼**——探点之间全程步行可达。

### 任务 2：每关拍 1 张参考照片（识图匹配用，硬约束：现场实拍）

识图 = Sobel 边缘 + 姿态 + 构图，参考照片必须是**现场实景照**（不能 AI 合成，
参考图与现场差异过大 → 匹配分压不到 55 门槛）。

拍摄卡（每关照此拍 1 张，竖构优先——手机主用设备和参考图 3:4 竖拍优先）：

```
构图：主题物(建筑立面/雕像/门头/树)x 居中偏左/右；远景带 1-2 个可辨认地标
      (楼檐、路灯、地砖花纹、指引牌)；
光线：白天自然光，避开正午顶光和直接逆光；阴影尽量少；
镜高：人站姿目视高度(约 1.6m)，平视不俯拍不仰拍(避免透视差)；
尺寸：手机相机直接拍,默认最高像素(我这边自动缩到 2048px/JPEG 0.85)；
命名：guan{01..06}-reference.jpg，存入同一文件夹，回传。
```

### 任务 3：每个探点取 WGS-84 坐标 + 高德底图截图

**坐标（不需要测距仪，用手机浏览器即可，与杭州版相同做法）：**

1. 打开任一手机浏览器（Safari/Chrome），访问 `https://aaron2000dq.github.io/?mode=nearby`
   → 点「展开固定彩排地图」。页面卡片里有两行数字，**只读「我的位置读数」那一行**
   （另一行带虚线框的是配置里的目标点坐标，不是你所处的位置；早先的 SOP 在这里
   说反了，会让人把目标点抄成新点位）。旁边有「复制我的坐标」按钮。
   ※ 桌面端也可用正式地图的制图人控制台：长按左下罗盘 3 秒 → PIN `1104` →
   读「定位读数」（同一路径可「导出当前勘测点」存 JSON）。
2. 站在探点中心（就是 30 米半径圈的心），读页面显示的精度 ±XXm ≤ 15m 才记；
   若 >15m，站定 20 秒等重定位（手机 GPS 精度一般 8-15m）。
   彩排页的坐标与精度会实时刷新，读数行下方括号里会直接写「可记录」或
   「>15m，站定等重定位再记」。
3. 记录：`纬度, 经度, 精度, 手机型号, 时间`（与模板文末顺序一致），6 点做一张表。
4. 把 6 点按顺序标进下面的"坐标表"。

**底图：不需要你截图了（2026-09-12 取消）。**
底图改为 App 运行时直取联网瓦片（高德，缩放级别按区域自动选），GCJ-02 → WGS-84 的
换算已在代码里（`src/lib/tiles.ts`），不需要现场截图，也不需要为每区手工配准。
现场没网时会自动降级成线稿模式并提示，雷达与提示不受影响。
