# Exploration Atlas

生日探索 PWA（成都版）：龙湖时代天街 → 成都合院 → 电子科技大学清水河校区，三站自走。
用浏览器 GPS 定位解锁探点（30 米）、复刻参考照的姿势与场景才能过关，靠近目标时雷达会滴滴响。

## 运行

```bash
npm install
npm run dev        # 本地开发
npm test           # 单测 + 构建 + PWA 契约
```

## 在手机上使用

必须在**真证书的 https 地址**上打开——浏览器只在安全上下文（https）里给定位权限，
`http://` 局域网地址下 GPS 会被直接禁用。本地调试用自签证书：

```bash
bash tools/make-dev-cert.sh        # 生成 .certs/（不入库）；换网络后重跑
npm run build && npm run preview   # 然后手机访问 https://<本机IP>:4173/
```

首次打开会弹出证书警告（自签证书的正常现象），选择「继续访问」；随后允许定位与相机权限，
可用浏览器分享菜单「添加到主屏幕」。

## 现场读坐标

`https://<地址>/geo-test.html` 是定位自检页：显示安全上下文、权限状态、实时坐标、精度与判定
（≤15 米才够 30 米解锁）。现场采集流程见 `docs/成都版-现场采集SOP-2026-09-08.md`。

## 兜底入口

长按地图右下角指南针 5 秒，输入 `1104` 进入引路人控制台：强制抵达、强制过关、模拟定位与重置。
照片与进度只保存在当前设备的 IndexedDB，不会上传服务器。

## 内容配置

地点、坐标、解锁半径、文案与参考照片集中在 `src/config/chengduStory.ts`，只填经纬度与文案，
几何（地图范围 / 路线 / 锚点）全部推导。运行时坐标一律 WGS-84；底图瓦片来自高德（GCJ-02），
转换在 `src/lib/tiles.ts` 内完成。
